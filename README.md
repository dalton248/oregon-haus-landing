# Oregon Haus — Landing Page

A modern, responsive landing page for **Oregon Haus**, a historic luxury Airbnb property located in the heart of the Oregon District in Dayton, Ohio.

## 🏠 About Oregon Haus
- **History:** Newly renovated former first German Methodist Church, combining rich historical architecture with modern luxury.
- **Capacity:** 6 Bedrooms | 9 Beds | 6 Bathrooms (Ideal for large groups, family reunions, and executive retreats).
- **Location:** Historic Oregon District, Dayton, OH — walkable to top dining, shops, and nightlife.
- **Rating:** ★ 4.95 Superhost Listing
- **Airbnb Listing:** [View on Airbnb](https://www.airbnb.com/rooms/1038646434083956823)

## 🛠️ Tech Stack
- **Framework:** React + Vite
- **Styling:** Tailwind CSS + Lucide React Icons
- **Typography:** Plus Jakarta Sans & Playfair Display
